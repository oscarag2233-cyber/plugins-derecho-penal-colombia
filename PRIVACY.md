# Política de privacidad — Plugins Derecho Penal Colombia

Versión: 2026-08-27

El servidor MCP de este repositorio está diseñado para consultar páginas públicas de fuentes oficiales de derecho penal colombiano. No requiere cuentas de usuario, no solicita credenciales y no almacena expedientes ni datos personales enviados en una conversación.

Durante una consulta, el servidor recibe el término de búsqueda o el identificador de una fuente permitida y puede realizar una solicitud HTTP de lectura a la URL oficial correspondiente. La respuesta se devuelve a ChatGPT con la URL canónica y la fecha de recuperación. El alojamiento donde se despliegue el servidor puede conservar registros técnicos; antes de una publicación pública, el editor debe configurar retención mínima, excluir contenido sensible de logs y publicar la URL definitiva de esta política.

No se debe enviar información confidencial, datos de víctimas, menores, historias clínicas, identificaciones, secretos profesionales o documentos reservados a través de este servidor.

La información jurídica puede cambiar. La fuente oficial prevalece y este servicio no certifica vigencia ni sustituye asesoría profesional.
