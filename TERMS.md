# Términos de uso — Plugins Derecho Penal Colombia

Este plugin ofrece herramientas de consulta y organización de fuentes públicas para investigación jurídica. No presta representación legal, no crea una relación abogado-cliente y no garantiza resultados procesales ni la vigencia indefinida de una norma o precedente.

El usuario debe revisar el texto íntegro de cada norma o providencia, confirmar su vigencia a la fecha relevante y obtener asesoría profesional cuando exista riesgo para la libertad, términos, prescripción, competencia o derechos de víctimas.

Las fuentes de terceros se consultan en sus sitios oficiales. La disponibilidad, estructura o contenido de esos sitios puede cambiar.
