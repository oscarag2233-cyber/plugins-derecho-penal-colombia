# Matriz de jurisprudencia

| Campo | Contenido |
|---|---|
| Pregunta jurídica | Formulación concreta y neutral |
| Corporación / sala | Corte Constitucional, Corte Suprema — Sala Penal, JEP u otra |
| Providencia | Tipo, número, fecha, radicado o expediente, ponente |
| Hechos comparables | Qué coincide y qué difiere |
| Ratio decidendi | Regla necesaria para resolver el caso |
| Obiter / votos | Comentarios no decisorios, aclaraciones o salvamentos |
| Fuerza | Precedente, doctrina probable, reiteración o apoyo persuasivo |
| Estado | Vigente, distinguida, modificada, condicionada, superada o no verificada |
| Fuente | URL oficial y fecha de consulta |
| Aplicación | Cómo apoya o limita la tesis del caso |

No copies extensos apartes protegidos. Resume con precisión y enlaza el documento oficial.
