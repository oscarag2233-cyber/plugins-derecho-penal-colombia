# Soporte

Para reportar un error del servidor, una cita incorrecta o una fuente oficial que haya cambiado, abra un issue en el repositorio de GitHub indicando:

- herramienta usada (`search` o `fetch`);
- fecha y hora aproximada;
- fuente oficial o identificador afectado;
- comportamiento observado;
- información técnica no confidencial.

No incluya expedientes, nombres, identificaciones, credenciales ni información protegida por reserva o secreto profesional.
